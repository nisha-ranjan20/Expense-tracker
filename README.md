#  Expense Tracker

A modern expense tracking web application built with React.js and Vite.

## Features

- User Login & Signup
- Dashboard
- Add Expenses
- Transaction History
- Responsive UI
- React Router Navigation

## Tech Stack

- React.js
- Vite
- React Router DOM
- CSS / Tailwind CSS

## Installation

```bash
npm install
npm run dev
```
